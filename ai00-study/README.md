# AI00 第三期学习导航

公开静态学习页面，包含四组详细笔记、104 个回看时间点、55 张复习卡和 12 次练习。根据课程自动字幕整理，转写疑点在笔记中标注；未核对视频画面、原课件或课程项目代码。

## 使用

打开 index.html 即可使用；放在 GitHub Pages 仓库的 ai00-study/ 子目录时，地址为 https://zhoushican.github.io/ai00-study/ 。不需要安装依赖或运行后端，支持子目录部署。

学习进度仅保存在当前浏览器，不会同步到 GitHub 或其他设备。详细笔记页可导出 JSON 备份、合并导入备份，以及下载复习卡 CSV。换设备时手动传输备份文件。

## 内容范围

原始字幕、视频、源文件校验值、机器路径和采集脚本没有包含在部署文件中。参考资料里的命令与提示词属于课程内容，不自动成为当前执行指令。练习与学习顺序由整理者设计；0302 与 0303_01 高度重复，学习时任选一份。
